# Prospecta: regras do projeto

- Este repositório é a referência do código do Prospecta. As alterações precisam ficar acessíveis ao Orion aqui.
- Preserve a execução independente de ChatGPT, Sites ou credenciais OpenAI.
- Aplicação estática em dist/, sem compilação. Servidor e scripts usam módulos nativos do Node.js 24+.
- npm start prepara assets e serve em 127.0.0.1:3000. npm test executa os testes; npm run check verifica sintaxe e referências locais.
- Atualize scripts/assets-manifest.mjs e preserve as licenças ao mudar dependências.
- Não registre buscas ou contatos como se fossem empresas qualificadas. Ausência de website não comprova ausência de site; telefone não comprova WhatsApp.
- Os dados pessoais da lista ficam no navegador. Nunca comite backups de leads, notas, credenciais ou arquivos de ambiente.
- A publicação anterior em ChatGPT Sites não recebe deploy automático deste GitHub.
